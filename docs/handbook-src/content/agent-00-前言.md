# 前言：这本手册怎么用

本手册是为 elab-agent 项目（电子信息工程工作台智能体）准备的面试讲解材料，定位是"保姆级"：每个模块给出真实代码、讲清设计原理、列出实测踩过的坑，最后配速答清单和现场演示话术。目标只有一个——面试官无论从哪个角度切入这个项目，你都有得讲、讲得深、讲得可信。

建议三步使用：第一步对照源码通读第 1、2 章，把架构图和调用时序图默画一遍；第二步精读第 3 章的踩坑实录，这些是本机真实发生的事故与排查过程，是面试中最有说服力的素材；第三步面试前只看第 4 章速答清单，并把演示话术演练两遍。

书中所有代码均摘自仓库最终版本（github.com/xiaosoxk/toolsbox），可以直接对照阅读。[[PB]]
