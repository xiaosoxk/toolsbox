# 第4章 高频速答清单与现场演示话术

## 4.1 高频问题速答（30 秒版）

| 问题 | 30 秒答案 |
|---|---|
| 这个 Agent 和 ChatGPT 插件有什么区别？ | 插件跑在厂商沙箱里摸不到本地软件；elab-agent 在本机进程里，能真实启动 MATLAB/Keil/CubeMX 并拿到它们的输出，是"能动手的 Agent"而非"能给建议的聊天"。 |
| Function calling 的流程？ | 工具以 JSON Schema 注册→请求带 tools 字段→模型返回 tool_calls（名称+参数 JSON 字符串）→本地执行→以 role=tool、tool_call_id 配对回填→模型基于结果继续，直到不再发起调用。 |
| 模型填错参数怎么办？ | 三层防御：Schema 约束源头；参数 JSON 解析失败容错为空参；注册表把 TypeError 归一为错误文本回喂，模型下一轮自纠。 |
| 怎么防止模型无限循环？ | max_steps 硬上限（默认 15）保证必然终止；超限时明确返回"缩小任务范围"的可操作提示。 |
| 工具输出很长怎么办？ | 注册表统一截断（默认 8000 字符），并在截断处标注原长；错误信息把"类型+消息"放首行再接 traceback，截断后关键字仍在。 |
| 为什么工具层和 LLM 层解耦？ | 无 key 时工具层可独立使用（doctor/report 零 LLM 依赖）；换厂商只改配置；测试互不牵连。 |
| 沙箱怎么做的？ | 所有文件工具路径 resolve 后必须仍在 workspace/ 内，否则拒绝；覆盖 ../ 与反斜杠两种逃逸变体；分级风险意识：个人工具路径白名单足够，多租户才上容器。 |
| MATLAB 集成最难的是什么？ | Windows 启动器不等待会话（要 -wait）；-batch 是 R2019a+ 参数、老版本会忽略并开桌面导致挂死；-r 报错会话不退出（try/catch+exit 兜底）；stdout 不转发（-logfile 落盘再读）。 |
| Keil/CubeMX 怎么集成的？ | Keil 用 UV4 -b 编译加 -o 日志，解析 Error/Warning 行；CubeMX 用 -q 脚本模式（config load + project generate）无头生成代码。 |
| Proteus/Multisim 为什么只做启动？ | 它们没有官方命令行/编程接口，假装能自动化是骗自己；正确姿势是启动+载入工程+给出人工操作指引，Agent 的边界感本身就是设计。 |
| 密钥怎么管理？ | 环境变量 ELAB_API_KEY（setx 用户级），代码与配置文件都不落盘；config.yaml 只有路径与模型名。 |
| 测试怎么做的？ | 15 个 pytest：FakeLLM 按剧本返回响应驱动完整循环（两步调用/历史复用/最大步数/坏参数），工具层直测（沙箱逃逸、Word 生成回读、注册表异常归一），全部秒级、零外部依赖。 |
| 依赖注入体现在哪？ | Agent 构造函数注入 client 与 registry；测试注入 FakeLLM。副作用可替换是可测试性的根源。 |
| 如果要支持多用户怎么办？ | 升级三件事：沙箱从路径白名单升级为容器级隔离；MATLAB 等 license 软件改任务队列串行复用会话；密钥与工作区按用户隔离。 |
| 项目最得意的一点？ | 对"做不到的事"诚实：能自动化的全部无头化，不能自动化的明确交接给人工，边界清晰比堆功能难得多。 |

## 4.2 现场演示脚本（照这个顺序演）

准备：提前 `python cli.py doctor` 截图（8/8 OK）；提前生成好 report.docx。

第一步（30 秒）：`python cli.py doctor` —— 讲"体检命令证明所有工具路径真实有效，这是项目'能用'而非'看起来能用'的证据"。

第二步（60 秒）：`python cli.py report` —— 离线生成 RC 阶跃响应实验报告并自动用 WPS 打开。讲点：全程零 LLM 依赖，工具层可独立复用；报告含 matplotlib 出图、数据表格、宋体/黑体中文排版。

第三步（90 秒，可选）：若配了 API key，`python cli.py task "用Python验证勾股数并生成验证报告"`，让面试官看 messages 流：模型决策→工具调用→观察→再决策→最终回答。

第四步（讲代码）：打开 registry.py 讲异常归一与截断（2.1 节），打开 matlab_tool.py 讲 R2016b 兼容方案（3.2 节）。

## 4.3 STAR 结构的项目陈述（2 分钟版）

S（情境）：电子信息工作流工具割裂，一次实验要在五六个软件间手动搬运数据。
T（任务）：做一个本地 Agent，把这些工具统一封装并让 LLM 自主编排，同时保持完全可控。
A（行动）：设计注册表协议层抹平八种异构接口；实现 ReAct 循环（消息协议、异常归一、步数兜底）；MATLAB/Keil/CubeMX 深度踩坑后做成全版本兼容；workspace 沙箱防注入；15 个零外部依赖的测试。
R（结果）：doctor 体检 8/8 通过、报告生成全链路可用、已开源（toolsbox 仓库）；更重要的是沉淀了七个可复述的工程踩坑与一套"时间量级→进程状态→环境事实→改代码"的排查方法论。
