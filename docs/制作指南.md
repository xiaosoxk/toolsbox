# docs/ 目录说明与制作指南

本目录包含项目面试讲解手册及其全部制作源文件，可独立复现。

## 目录结构

```
docs/
├── elab-agent项目面试讲解手册.docx   # 成品手册（Word，约 18 页）
├── 制作指南.md                       # 本文件
└── handbook-src/                     # 手册制作源文件（可完整复现）
    ├── content/                      # 手册正文（Markdown，5 个章节文件）
    │   ├── agent-00-前言.md
    │   ├── agent-01-定位与架构.md
    │   ├── agent-02-核心模块.md
    │   ├── agent-03-踩坑实录.md
    │   └── agent-04-速答与演示.md
    ├── spec-elab.json                # 手册规格：章节清单 + 封面标题/副标题/元信息
    ├── generate.js                   # Markdown -> docx 生成器（Node + docx 包）
    ├── add_toc_placeholders.py       # 目录占位符注入（Word 打开前可读）
    ├── fix_toc_dup.py                # 首条目录去重 + 页码缓存修补
    ├── patch_pagenum.py              # 页码域修补（罗马/阿拉伯分段，WPS 兼容）
    ├── postcheck.py                  # 生成质量自检（9 项规则）
    └── package.json                  # Node 依赖声明（docx）
```

## 一、环境准备

- Node.js 18+（生成器用），Python 3.11+（后处理脚本用）；
- 后处理脚本依赖 defusedxml：`pip install defusedxml`（若缺）；
- 可选：LibreOffice（用于转 PDF 预览）。

## 二、重新生成手册（完整流水线）

```bash
cd docs/handbook-src
npm install docx                     # 首次需要
node generate.js spec-elab.json      # 1) 生成 docx 到仓库根目录

python add_toc_placeholders.py "../../elab-agent项目面试讲解手册.docx" --auto   # 2) 注入目录条目
python fix_toc_dup.py       "../../elab-agent项目面试讲解手册.docx"             # 3) 目录首条去重
python patch_pagenum.py     "../../elab-agent项目面试讲解手册.docx"             # 4) 页码域修补（封面无页码/前言罗马/正文阿拉伯）
python postcheck.py         "../../elab-agent项目面试讲解手册.docx"             # 5) 质量自检，须 9/9 通过
```

在 Word/WPS 中打开成品后，右键目录选择"更新域"即可刷新为精确页码。

要改手册内容：编辑 `content/` 对应 md（`#`=章、`##`=节、`###`=小节，`> `为"追问"标注，
``` 代码块，| 表格），改完从第 1) 步重跑。要改封面标题/元信息：改 spec-elab.json。

## 三、项目环境搭建与测试

```bash
# 仓库根目录
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
python -m pytest -q                  # 15 个用例，秒级，不启动任何外部软件
python cli.py doctor                 # 8 个外部工具路径体检
```

外部软件（MATLAB/Keil/Proteus/Multisim/CubeMX/WPS）路径在仓库根 `config.yaml`，
按本机实际安装位置修改即可；`python cli.py doctor --matlab` 可真实调用一次 MATLAB 验证。

## 四、LLM 接入（可选）

chat/task 模式需要 API key（OpenAI 兼容协议）：PowerShell 执行
`setx ELAB_API_KEY "sk-xxx"` 后重开终端；厂商在 config.yaml 的 llm.api_base 切换
（智谱 GLM / DeepSeek / 本地 Ollama 均可）。无 key 时 doctor/report 与全部工具不受影响。
